# 前端操作手册

本文描述 SkillHub Web 前端的 **页面结构** 与 **全流程操作**，覆盖普通用户、创作者与审核管理员。

## 全局布局

全站采用统一 **顶部导航栏**（`AppHeader`）：

| 区域 | 功能 |
|------|------|
| 左侧 Logo | 点击返回首页 `/` |
| 右侧「+ 发布」 | 登录后可见；打开发布抽屉（个人中心页可隐藏） |
| openJiuwen 外链 | 跳转 openJiuwen 官网 |
| 语言切换 | 中文 / English |
| 通知铃铛 | 登录后可见；审核结果、版本动态等 |
| 用户菜单 | 个人中心、退出登录 |

---

## 首页（Skill 市场）

**路径**：`/`

> 页面标题仍沿用「插件市场」历史命名，实际展示的是 Skill / Swarm Skill 资产。

### 页面结构

- **Hero 区**：产品 Slogan 与 Skill / Swarm Skill 类型切换
- **左侧分类导航**：热门、最新、全部及业务分类（开发编程、办公与生产力等）
- **主列表区**：网格或表格视图，支持关键词搜索
- **Skill 卡片**：名称、简介、版本、浏览/下载/点赞数、置顶标识等

### 常用操作

| 操作 | 步骤 |
|------|------|
| 搜索 | 顶部搜索框输入名称或描述关键词 |
| 切换 Skill 类型 | 在 Skill / Swarm Skill 之间切换 |
| 查看详情 | 点击卡片进入 `/skills/:assetId` |
| 点赞 / 收藏 | 在卡片或详情页操作（须登录，且不能操作自己的作品） |
| 下载 | 详情页选择版本后下载 zip |

---

## Skill 公开市场详情

**路径**：`/skills/:assetId`

### 展示内容

- 基本信息：名称、发布者、更新时间、标签
- 描述与 Markdown 详细说明
- **版本更新日志**（按所选版本加载）
- 包内 **文件列表**（文本文件可在线预览）
- 审核管理员在此页可对 **待审版本** 执行通过/驳回

### 下载

1. 在「下载版本」下拉框选择版本（公开市场仅展示 **已通过审核** 的对外版本）
2. 点击下载，浏览器通过预签名 URL 拉取 zip

---

## 登录

**路径**：`/login`

- 支持 **GitCode**、**GitHub** OAuth（以服务端 `MARKET_*_OAUTH_ENABLED` 为准）
- 登录前访问受保护页会自动记录回跳路径，登录成功后返回原页面
- 退出登录：个人中心侧栏 **退出登录**

## 发布 Skill

发布入口：**右上角「+ 发布」** → 右侧 **发布抽屉**（`/profile/publish` 旧路由会自动打开抽屉并跳回个人中心）。

### 首次发布（新 Skill）

1. 在「关联 Skill」选择 **「新 Skill（首次发布）」**
2. 填写字段：

| 字段 | 要求 |
|------|------|
| 技能名 `name` | 小写字母开头，仅含小写字母、数字、连字符，最长 64 字符 |
| 显示名 | 1～128 字符，列表与详情展示用 |
| 版本号 | 三段式，如 `1.0.0`（可选前缀 `v`） |
| 描述 | 可选；留空则使用 `SKILL.md` YAML 头中的 `description` |
| 标签 | 英文或中文逗号分隔 |
| 图标 | PNG，≤ 5MB，写入包根 `icon.png` |
| Skill 目录 | 须含 **根级 `SKILL.md`**；Team Skill 须满足 `roles` 等 frontmatter 规则 |

3. 可选填写 **版本说明**（changelog）
4. 点击 **上传发布**；浏览器自动计算 SHA-256 校验和并上传

### 发布新版本

1. 「关联 Skill」下拉中选择 **已有 Skill**
2. 技能名、显示名 **锁定不可改**；可更新描述、标签、图标与目录内容
3. 填写 **新版本号**（须高于已有版本或勾选 **强制覆盖** 同版本）
4. 提交后新版本进入审核；**市场对外版本在审核通过前不会切换**

### 发布结果说明

| 状态 | 含义 |
|------|------|
| 系统审查中 | 已启用 `MARKET_SKILL_REVIEW_ENABLED`，AI/规则审查进行中 |
| 人工审核中 | 等待审核管理员处理 |
| 发布成功 | 已通过全部环节，对外可见（若为首版或新版本审核通过） |
| 发布失败（系统审查不通过） | 可在个人中心查看 **系统审查详情** |
| 发布失败（人工审核失败） | 查看驳回原因，修改后重新发布新版本 |

### 下载发布模板

发布抽屉内 **「下载 Skill 模板」** 依赖服务端配置 `MARKET_SKILL_TEMPLATE_OBJECT_KEY`。未配置时按钮会提示联系管理员。

## 个人中心

**路径**：`/profile`（须登录）

### 侧栏菜单

| 菜单项 | 可见性 | 说明 |
|--------|--------|------|
| 我的 Skills | 所有登录用户 | 我发布的 Skill 列表 |
| 我的收藏 | 所有登录用户 | 收藏的 Skill |
| 我的点赞 | 所有登录用户 | 点赞过的 Skill |
| Git 源 | 所有登录用户 | 绑定公开 Git 仓库批量同步 |
| 待审核 | **审核管理员** | 待人工审核的 Skill 列表 |
| 审核历史 | **审核管理员** | 本人审核操作记录 |
| 审计日志 | **审核管理员** | 平台操作审计（查询、统计、导出） |

URL 参数 `?tab=` 可直达：`skill`（默认）、`stars`、`likes`、`git`、`pending`、`audit`、`audit-log`。

### 我的 Skills 列表

- 搜索、分页浏览已发布 Skill
- 卡片展示 **上架审核状态**、**新版本审核中** 等标识
- **查看详情**：进入版本管理页
- **删除**：删除该 Skill **全部版本**（不可恢复）
- **系统审查详情**：审查中或失败时可跳转

### 我的 Skill 详情与版本管理

**路径**：`/profile/plugins/:assetId`

| 操作 | 说明 |
|------|------|
| 切换版本 | 下拉选择历史版本，查看 changelog、文件、审核状态 |
| 删除该版本 | 仅删除选定版本，其余版本保留 |
| 删除全部版本 | 删除整个 Skill 资产 |
| 再次发布 | 返回个人中心后点击「+ 发布」，选择关联 Skill |

> 非审核通过版本的内容 **不会** 在公开市场展示；发布者在个人中心可见全部版本状态。

### 我的收藏 / 我的点赞

- 分页列表，点击卡片进入公开市场详情
- 在详情页可取消收藏或再次点赞

### Git 源

**路径**：`/profile?tab=git`

用于从 **公开 HTTPS Git 仓库** 批量导入 Skill：

1. 填写仓库 URL、分支/tag（可选）、技能根目录 `skills_subpath`（可选）
2. 创建后触发 **后台同步**；列表展示同步状态（同步中 / 成功 / 部分失败 / 失败）
3. 可对已有源 **再次同步** 或 **删除** 注册记录

限制摘要：

- 仅支持 **公开** 仓库；私仓不支持
- 不允许内网、本机、保留地址等不安全 URL
- `skills_subpath` 不可含 `..` 或路径穿越
- 同一仓库+分支+子路径 **全局唯一**，不可重复注册

## 消息通知

**入口**：顶部 **通知铃铛**

- 自动轮询未读通知（约 60 秒）
- 典型内容：审核通过/驳回、新版本待审提醒（审核员）等
- 打开面板后可 **全部标记已读**

## 审核管理员操作

审核管理员由服务端 `MARKET_REVIEW_ADMIN_USERNAMES` 配置（GitCode/GitHub **登录名** 精确匹配）。登录后个人中心侧栏出现 **待审核**、**审核历史**、**审计日志**。

### 待审核列表

**路径**：`/profile?tab=pending`

- 展示 `moderation_status=PENDING` 的 Skill
- 点击进入 Skill 详情或公开市场详情页执行审核

### 审核通过 / 驳回

在 Skill 详情页 **「上架审核」** 区域：

1. **审核通过**：该版本对外可见；若为新版本，市场 `latest_version` 更新
2. **审核不通过**：**必填驳回原因**；发布者收到通知，需修改后发布新版本

注意：

- Skill 处于 **系统审查中** 时，人工审核按钮不可用
- 已驳回版本不可再次驳回；审核员可 **审核通过** 以恢复上架，或等待发布者 **发布新版本**
- 已通过的版本不可驳回

### 审核历史

**路径**：`/profile?tab=audit`

查看本人历史 **通过/驳回** 记录及原因。

### 审计日志

**路径**：`/profile?tab=audit-log`

- 查询平台全量操作审计（发布、删除、审核、Git 同步、下载等）
- 支持时间范围、操作类型等筛选
- 可导出 CSV（单次上限 5 万条）

### 系统审查详情

**路径**：`/profile/plugins/:assetId/versions/:version/review`

- 展示规则扫描、AI 语义复核等维度结果
- 发布者与审核员均可查看（Skill 类型且审查已执行时）
