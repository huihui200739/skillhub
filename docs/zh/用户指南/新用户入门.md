# 新用户入门

本文帮助你在 **5～10 分钟内** 了解 SkillHub 是什么、适合哪些场景，并完成第一次浏览或发布体验。

## 产品定位

**SkillHub**（前端品牌名 **Swarm Skills Hub**）是 openJiuwen 生态中的 **Skill 托管与分发平台**。你可以把它理解为：

- 面向 Agent / 多智协同场景的 **技能（Skill）应用商店**
- 支持 **Skill** 与 **Swarm Skill** 两类技能资产（后者也称 Team Skill；API 类型为 `swarmskill`）
- 提供 **Web 浏览与下载**、**CLI 检索安装**，以及可选的 **ClawHub 兼容协议** 对接

**官方托管地址**：[swarmskills.openjiuwen.com](https://swarmskills.openjiuwen.com)  
团队若需数据驻留或内网隔离，可在本仓库基础上 **自建部署**（见 [安装指导](../安装指导/本地安装/安装指导.md)）。

## 典型业务场景

| 场景 | 说明 |
|------|------|
| **发现与复用 Skill** | 在首页按分类、关键词搜索，查看详情、下载 zip，或通过 CLI 安装到本地 Agent 环境 |
| **发布团队 Skill** | 创作者将本地 Skill 目录打包发布到 Hub，经审核后供团队或公开用户安装 |
| **版本迭代** | 对已有 Skill 发布新版本，保留历史版本；市场默认展示 **已通过审核的最新对外版本** |
| **Git 仓库批量同步** | 绑定公开 Git 仓库，按目录结构批量导入/更新 Skill（见个人中心「Git 源」） |
| **内容合规审核** | 审核管理员对待审 Skill 执行通过/驳回；可选启用 **系统审查（AI + 规则）** 作为人工审核前置 |
| **与 openJiuwen / Claw 集成** | 通过 CLI（`jiuwen-teamskills` 或 `openjiuwen-plugin`）或 HTTP API 对接自有流水线 |

## 核心概念

| 概念 | 说明 |
|------|------|
| **Skill** | 单个 Agent 技能包，根目录须含 `SKILL.md`，可含 scripts、references 等 |
| **Swarm Skill** | 多角色协同类 Skill；`SKILL.md` frontmatter 中 `kind` 为 `team-skill` 或 `swarm-skill`，且须定义 `roles`（至少 2 个角色） |
| **版本** | 语义化版本号，如 `1.0.0`；每次发布产生一个新版本记录 |
| **审核状态** | `PENDING`（审核中）、`APPROVED`（已通过）、`REJECTED`（已驳回） |
| **发布阶段** | 可选 **系统审查** → **人工审核** → **市场上架**；管理员发布或关闭审查时可跳过部分环节 |

## 快速上手（官方托管）

### 1. 访问与登录

1. 打开 [swarmskills.openjiuwen.com](https://swarmskills.openjiuwen.com)
2. 点击右上角进入 **登录**（支持 GitCode / GitHub OAuth，以实例配置为准）
3. 授权完成后自动回到站点

> 自建实例需管理员预先配置 OAuth，见 [环境配置说明（使用者）](./环境配置说明.md)。

### 2. 浏览与下载 Skill

1. 在 **首页** 使用左侧分类或顶部搜索框筛选 Skill / Swarm Skill
2. 点击卡片进入 **详情页**，查看描述、版本更新日志、包内文件
3. 点击 **下载** 获取当前对外版本的 zip 包

未登录用户也可浏览公开市场；**点赞、收藏** 需登录，且不能对自己的作品点赞/收藏。

### 3. 发布第一个 Skill（创作者）

1. 登录后点击右上角 **「+ 发布」**，右侧打开发布抽屉
2. 点击 **「下载 Skill 模板」**（若可用），或参考模板目录结构准备本地 Skill 文件夹
3. 填写 **技能名**、**显示名**、**版本号**、**描述/标签**，上传 **PNG 图标** 与 **Skill 目录**
4. 提交后进入 **个人中心 → 我的 Skills**，查看「发布结果」与审核状态
5. 审核通过后，Skill 出现在首页公开市场

详细字段说明与操作截图级步骤见 [前端操作手册](./前端操作手册.md#发布-skill)。

### 4. 使用 CLI 安装（可选）

```bash
pip install jiuwen-teamskills   # 通用 Skill CLI；亦可使用 openjiuwen-plugin
jiuwen-teamskills search <关键词>
jiuwen-teamskills install <skill-name>
```

CLI 完整说明见 [cli/README.md](../../../cli/README.md)。默认市场地址由 CLI 配置或环境变量（如 `TEAMSKILLS_HUB_URL`）决定；自建实例须显式指定 Hub 地址。

## 页面导航一览

| 路径 | 页面 | 需登录 |
|------|------|--------|
| `/` | 插件市场 / Skill 列表 | 否（互动需登录） |
| `/skills/:assetId` | Skill 公开市场详情 | 否 |
| `/login` | OAuth 登录 | 否 |
| `/profile` | 个人中心（我的 Skills、收藏、点赞等） | 是 |
| `/profile/plugins/:assetId` | 我的 Skill 详情与版本管理 | 是 |
| `/profile/plugins/:assetId/versions/:version/review` | 系统审查详情 | 是（发布者/审核员） |
| `/privacy-statement` | 隐私声明 | 否 |
